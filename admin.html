관리자 열쇠

이 기기에 열쇠가 연결되어 있습니다. 여기서 저장할 수 있습니다.

저장하려면 GitHub에서 만든 이 사이트 전용 열쇠(토큰)를 한 번 넣어 주세요. 열쇠가 없는 기기에서는 보기만 됩니다.

  1. GitHub 열쇠 만들기 를 엽니다 (로그인 필요).
  2. Token name: ICU 정기모임 · Expiration: 원하는 기간
  3. Repository access: Only select repositories → icu
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token → 나온 github_pat_… 를 복사해 아래에 붙여 넣습니다.

열쇠는 이 기기의 브라우저에만 저장되고 GitHub 말고는 어디에도 보내지 않습니다.

정기모임 일정 정하기

분기 표시는 날짜로 자동 계산됩니다. 모임 날짜가 지나면 회원 화면은 다음 분기 회칙 날짜로 넘어갑니다.

정해 둔 일정

    아직 정해 둔 일정이 없습니다. 회원 화면에는 회칙 날짜가 ‘예정’으로 보입니다.

    참석 체크

    모임 날짜를 고르고 온 회원을 누르세요. 저장하면 회원 화면 ‘모임 결산’의 참석 명단과 참석률에 반영됩니다. (그 모임의 결제가 은행 거래내역에 들어오면 그 카드에 붙습니다.)

    게스트는 참석 명단에 따로 표시되고, 참석률은 회원만으로 계산합니다.
